# Smart Emergency Search Engine (SESE) — Simulation Code

## Overview
This repository contains the discrete-event simulation code
for the paper:

> **"A Smart Emergency Search Engine for Real-Time Medical
> Resource Discovery"**

The simulation evaluates the SESE framework against two
baseline routing conditions across 258 emergency requests
and 50 synthetic hospital profiles over a 24-hour window.
